🌌 **YATHARTH**

Because Not Everything That Sounds Right Is True. Beyond Answers, Towards Truth. 🚀 Information evolves, but truth endures.

✨ About In a world where AI is becoming part of our everyday lives, one important question remains:

Can we really trust everything AI tells us?

YATHARTH is an AI-powered temporal verification layer. It detects outdated claims in AI-generated responses, validates them against live evidence, measures how fresh the information is, and automatically repairs stale answers, with sources so users can make more informed decisions.

Prices change, APIs get deprecated, laws are updated and leaders move on, yet AI keeps stating old information as fact with full confidence. YATHARTH exists to catch that.
**
🌟 What It Does ?**
YATHARTH works in three stages:

Detect: finds the time-sensitive claims: prices, versions, laws and leaders. Validate: re-checks every flagged claim against live, trusted web sources. Measure and repair: scores freshness, explains what changed, and rewrites the stale answer.

**Features**

🎨 Color-coded answer: green, amber and red show freshness at a glance. 📊 Freshness score: 0-100 per claim and overall. 📝 Why it changed: old vs new value, with reasoning and source. 🔄 Comparison: old answer vs current evidence, side by side. 🧠 Reasoning: explains every verdict step by step. ⚖️ Law and article checks: checks cited laws and articles for updates. 🔁 Recheck: re-verifies claims on demand or on a schedule. ✅ Repaired answer: stale claims fixed with citations. 🧩 Browser extension: verify output from ChatGPT, Claude, Gemini or any AI app in one click.

💡 **Why YATHARTH?**
AI can make information easier to access, but reliable information matters just as much as quick answers. YATHARTH is built around the idea that technology should not only provide answers. It should also help us examine where those answers come from.

It helps everyone who relies on AI:

👨‍💻 Developers who might build on deprecated APIs 🎓 Students who might cite outdated facts 🏢 Businesses that might decide on old pricing 🙋 Everyday users who might trust confident errors What makes it different: it gives a per-claim freshness score, works with any AI, explains why data changed, rewrites the stale answer, and cites its sources.

🛠️ **Tools Used **
Layer Technology Role in YATHARTH 🔎 Live search Tavily Search and Extract APIs fetch current, dated evidence 🚦 Model gateway Bifrost by Maxim AI Routes all LLM calls with fallbacks and cost tracking ⚙️ Backend Python + FastAPI Claim pipeline, scoring engine, REST API and Redis cache 🧩 Browser extension Chrome extension Verify any bot output in one click, plus an MCP server and OpenAPI 🎨 Design + frontend Lovable + React Design and prototype the UI with Lovable; build the dashboard with color-coded answers and source panels How the tools fit together

Tavily supplies the live evidence. Its Search and Extract APIs pull current, dated information from the web, which is compared with what the AI claimed. Bifrost handles every LLM call in the pipeline: extracting claims, flagging volatile ones, judging evidence, and rewriting answers. It adds fallbacks if a model fails, plus cost tracking, and also routes LLM translation so claims can be verified across languages. FastAPI holds the claim pipeline, the freshness scoring engine, and the REST API. A Redis cache keeps repeated searches fast and cheap. The web app, extension and API all share this one backend. Chrome extension, MCP server and OpenAPI let users and other tools plug YATHARTH into any AI chat. Lovable + React power the interface: Lovable for design and prototyping, React for the dashboard.
